-------

- Completion detection accepts CRLF, CR-NUL, doubled CR and fragmented replies.
- Commands are logged/flushed BEFORE transmission; decoded response chunks
  are saved immediately with escaped bytes in staging-actions.txt.
- Connection/login/shell-ready/command progress now appears on the console.
- Separate default10-second Telnet timeout (--telnet-timeout), FTP stays30.
- One staging failure stops further commands on that session, while normal
  FTP files continue. The failed session is closed at collection finish.
- runtime-targets.json reports target_availability and all_targets_available,
  separate from discovery's missing_basenames list.
- Both collectors still use the same project delphi-dump folder. Existing
  successful files are preserved, and each attempt keeps separate manifests.
