The native sink bodies establish these callback slot associations. The callback
object is eight bytes (vptr + owner pointer at +4), constructed at app 0x125ca0.
The data callback follows owner+0x18 to the existing decoder and calls the native
ackFrames(session,1) path when its decoder entry returns zero. Media configuration
writes owner+0x1c. The focus callback invokes the existing app controller paths.
Therefore reusing the primary owner/adapter would entangle the main display.
The secondary needs an independent callback object, decoder state and focus/ack
state. It cannot safely use a byte copy of the live primary sink or callback.

Native handleSetup accepts codec enum 3; it calls callback slot 0x14, then
sendConfig(2). Byte +0x30 controls an additional setVideoFocus(1,true) after setup.
This recovers the behavior of that constructor byte, but a new endpoint's focus
policy must be independent and tested. Config/ack/focus queues use endpoint
router+8/channel+5; they must never use the primary's channel/session by accident.

Construction chain:
- App allocates VideoSink with operator new(0x50).
- Local constructor 0x12165c(this,id,router,auto-focus-byte) calls MediaSinkBase
  constructor 0x1215d8, itself calling ProtocolEndpointBase constructor 0x1208fc.
- Base initializes ready/channel bytes +4/+5 to zero, router +8, widened service
  ID at +0xc and a byte at +0x10. Media base initializes session +0x18 to -1 and
  its vector at +0x20; it does not establish every later wrapper setting.
- Video constructor assigns its native vptr, byte +0x30, empty callback shared
  pointer at +0x34, config vector at +0x3c, and zero word +0x4c.
- Main initialization separately attaches callbacks and sets word +0x1c to 4.
An empty vector includes ABI-specific allocator state; do not assume a byte copy
of an existing vector or a guessed all-zero foreign C++ object is a constructor.
The exported VideoSink constructor is absent. A future factory must either use
the exact profiled native constructor with validated app relocation, or implement
and verify the whole compatible endpoint/ownership ABI.
