  stores 1 into the process descriptor at +0x2c. This is -r in AndroidAuto's
  previously captured procman_core.cfg entry.
- Process-exit code at 0x104260..0x10429c tests that +0x2c is nonzero, the
  descriptor's exit-code word +0x34 is nonzero, and global 0x12ff70 is zero.
  That path calls 0x103dec and sets process state +0x38 to 1.
- 0x103dec schedules the launch worker 0x10433c; the worker invokes spawnp
  at 0x104504. Thus -r enables a conditional restart-on-error path. This
  is not evidence that every normal exit is automatically restarted.

  descriptor +0x34 is nonzero. A controlled restoration must preserve the

- Embedded usage documents a separate manager instance via XSAL_INSTANCE_NAME,
  but does not document a per-app runtime preload/stop option. No such command
