This supersedes the synthetic logging model with a compiled production candidate.
It intentionally supersedes the earlier enter/leave specification with ENTRY-ONLY
observation and an ARM tail branch, avoiding any assumption about the vendor's
return type or C++ unwinder. Native return and exception paths have no observer
frame. Endpoint objects and video/discovery data are never read or altered.

Capture fields: caller LR, receiver/endpoint scalar identities, PID/thread ID,
global/per-thread accepted-record sequence. All callers are recorded. Native
symbol address and module base are recorded in the fixed header. The logger
uses a prefaulted shared RAM mapping, one try-lock, fixed 1024-record capacity,
saturating/bounded-effort drop accounting, and no normal-path file I/O, allocation,
formatting or loader calls. Imports bind eagerly. Log failures preserve forwarding.
Original-symbol absence/wrong owner refuses startup with exit 125; see README.
