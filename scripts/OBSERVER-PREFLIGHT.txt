Observer vehicle preflight - Python entry point

Run from . on the connected laptop.
Keep the Ethernet adapter connected and the phone unplugged. The captures confirm
AndroidAuto and its receiver remain running in that state.

Current next step - process-manager information only (seven read-only commands):
  python scripts/collect_observer_preflight.py --supervisor-only
This captures procman_core.cfg, process ancestry, procman arguments/fds/maps and
AndroidAuto arguments/maps. It skips FTP, passwords for FTP, and the release
manifest. It requires this script plus sibling delphi_inventory.py.

Full preflight - all fourteen shell commands plus three fresh binary downloads:
  python scripts/collect_observer_preflight.py
Full mode requires native/observer/release/manifest.json for SHA256 comparison.
It now includes the supervisor information by default, avoiding a separate
startup-policy pass when collecting a new full baseline.

If using the Windows Python launcher, replace python with py -3.
Optional unit address (default 192.168.1.4):
  python scripts/collect_observer_preflight.py --supervisor-only --host <address>
For a non-default FTP password in FULL mode, add --ask-password. Telnet prompts
for its password only if the unit requests one. Authentication is not transcribed.

All results go into a fresh delphi-dump/_observer_preflight_* directory relative
to the project containing scripts/. Run location does not change that destination.
Existing dump data is not reused or overwritten. Copy the new folder back into
this workspace's delphi-dump if collecting on another laptop.

READY FOR REVIEW means the requested collection checks passed; it does not mean
that observer deployment or a process restart is ready. Supervisor-only results
explicitly state that no fresh firmware hashes were collected in that run.
Keep INCOMPLETE results too: errors and partial transcripts are retained for review.
The process environment is saved locally, not printed to the console.

The vehicle commands are read-only. No upload, vehicle file write, termination,
restart, or observer launch is performed by this script.
